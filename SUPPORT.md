# Support

For bugs, installation issues, and feature requests, use GitHub Issues.

Before opening an issue, please include:

- operating system
- Python and conda versions
- how the app was started
- selected LLM backend
- whether the PLUS runtime exists under `plus-backend/cpp`
- relevant terminal error text

Do not attach API keys, `.env`, local databases, private GIS data, or generated outputs that contain sensitive information.
